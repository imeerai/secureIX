Gateway Responsibilities
  • 1.1 Header Injector: Sets nosniff, X-Frame-Options DENY, XSS-Protection, COOP, and CSP on every response.
  • 1.2 CORS Handler: Wildcard origin, GET/POST/OPTIONS, and short-circuits preflight OPTIONS with 204.
  • 1.3 Router: Matches pathname/method to /api/health, /api/scan, /api/techstack, /api/benchmark, /api/history(/trend), /api/seo/analyze(/history), else static fallback.
  • 1.4 SSRF/URL Validator: Blocks dangerous schemes, injection payloads, 2048-char overflow, and private/loopback/metadata IP ranges before any outbound probe.
  • 1.5 Rate Limiter: In-memory sliding-window bucket per client IP with periodic stale-bucket eviction and Retry-After signaling.
Rejected Request Outcomes
  • 429 Too Many Requests: Rate limit bucket exceeded; includes Retry-After and window metadata.
  • 400 Bad Request: Malformed URL, disallowed scheme, or injection payload detected.
  • 403-class Policy Violation: SSRF protection blocks private/internal/loopback or cloud metadata targets.

Security Evaluation Channels
  • SSL/TLS Posture: Expiration date, SAN list, cipher suite strength.
  • HTTP Defense Headers: HSTS, CSP, X-Frame-Options, X-Content-Type-Options.
  • DNSSEC & Email Auth: CAA authorization, SPF directives, DMARC policy.
  • Cookie & CORS: HttpOnly, Secure, SameSite, and wildcard Origin checks.
  • Heuristic Spoofing: Punycode homograph, entropy, and brand name mimicking.
Grading Scale (P2.7)
  • Score 90–100: Grade A+ / A (EXCELLENT / VERY SECURE)
  • Score 80–89: Grade B (GOOD / SECURE)
  • Score 65–79: Grade C (FAIR / HARDENING RECOMMENDED)
  • Score 50–64: Grade D (POOR / VULNERABILITIES DETECTED)
  • Score 0–49: Grade F (CRITICAL / HIGH RISK POSTURE)

Benchmark Pipeline
  • 5.1 Scan Invoker: Reuses P2.0's full performScan() to obtain a SecureIX score, grade, and channel data with no duplicate probing.
  • 5.2 Live API Client: POSTs to http-observatory.security.mozilla.org with a 3.5s timeout for near real-time responsiveness.
  • 5.3 Local Fallback Evaluator: Reimplements the Mozilla Observatory scoring spec (CSP -25, HSTS -20, XFO -20, XCTO -5, Referrer-Policy -5, Cookies -10, HTTPS -20) when the live API is throttled or unreachable.
  • 5.4 Matrix Builder: Produces a 6-dimension comparison covering header hardening, phishing heuristics, DNS anti-spoofing, sensitive file exposure, cookie/CORS policy, and TLS handshake health.
Comparison Verdicts
  • Positive Delta: SecureIX scored higher, typically credited to DNS/TLS/phishing checks Observatory omits.
  • Negative Delta: Observatory penalized headers more heavily; SecureIX still reports added perimeter vectors.
  • Zero Delta: Both engines align on overall security posture.
